# 1초 간격 LED 제어 및 시리얼 통신 시스템

## 1. 프로젝트 개요
아두이노(또는 가상 시뮬레이터)를 활용하여 1초 간격으로 LED를 안정적으로 토글(ON/OFF)하고, 현재 상태를 시리얼 모니터로 출력하는 프로젝트입니다.

## 2. 주요 기능
- `millis()` 함수 기반의 비동기 타이머 적용 (1초 간격 LED 상태 반전)
- 시리얼 통신(Baud rate: 9600)을 통해 실시간 LED 상태 (`LED Status: ON/OFF`) 출력

## 3. 회로 및 소스코드
- **주요 핀 연결:** 디지털 13번 핀 $\rightarrow$ LED $\rightarrow$ GND
- 전체 소스코드는 `main.ino` 파일에서 확인할 수 있습니다.
